# 使用说明

## 安装命令入口（Codex 优先）

首次安装按顺序执行整组命令：先安装 Codex 查询和提醒插件，再安装桌面程序并自动启动：

```powershell
codex plugin marketplace add FantasyWorld-G/codex-reset-pet --ref v0.4.8
codex plugin add reset-reminder@codex-reset-pet
codex plugin list --marketplace codex-reset-pet

# 安装桌面小精灵并立即启动（配套插件已在上面安装）
$f = Join-Path $env:TEMP 'codex-reset-pet-install.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/FantasyWorld-G/codex-reset-pet/v0.4.8/install.ps1' -OutFile $f; powershell -NoProfile -ExecutionPolicy Bypass -File $f -SkipPlugin
```

最后一行会安装并启动桌面小精灵；`-SkipPlugin` 只是避免重复注册插件。仅需插件时执行前三行即可。安装后新建 Codex 聊天同步账户，未同步也会先显示小精灵。其他安装方式见下表。

## 安装与启动

安装后重新打开终端，输入下面这一条即可启动，无需调用 Codex AI：

```powershell
codex-pet
```

`codex-pet start` 同样可用，`codex-pet status` 查看运行状态，`codex-pet version` 查看版本。已运行时不会重复打开。此命令属于本项目，不是 `codex` 的子命令；启动本身无需联网或模型额度，账户刷新和 Tibo 查询仍需网络。

安装器会将安装目录的 `bin` 追加到当前用户 PATH。现有终端可能需要完全关闭后重新打开（包括 Codex 内置终端的宿主应用）。不想修改 PATH 时，安装或更新加 `-NoPath`，之后通过桌面快捷方式启动，或执行 `& "$env:LOCALAPPDATA\CodexResetPet\bin\codex-pet.cmd"`；自定义安装则替换为对应目录。

推荐使用首页的一键安装命令。默认安装到 `%LOCALAPPDATA%\CodexResetPet`，桌面快捷方式名为 `Codex Reset Pet`。关闭后双击快捷方式即可重新启动。

目录如下：

```text
CodexResetPet/
  app/0.4.8/       程序、角色素材、说明书和插件目录
  bin/            codex-pet 命令入口
  runtime/        独立 Python 虚拟环境及 Pillow
  data/           仅本机保存的账户快照、窗口位置、日志
  install.json    安装位置与版本记录
```

安装器参数：

| 参数 | 用途 |
| --- | --- |
| `-NoPath` | 不修改用户 PATH，仍创建启动命令文件 |
| `-NoLaunch` | 安装完成后暂不启动 |
| `-NoShortcut` | 不创建桌面快捷方式 |
| `-SkipPlugin` | 只安装桌面程序，跳过 Codex 插件注册 |
| `-InstallRoot 'D:\Apps\CodexResetPet'` | 自定义安装位置 |
| `-SourcePath 'C:\path\codex-reset-pet'` | 从已下载的源码安装，仍需安装 Python 依赖 |

例如：`powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -SourcePath . -NoLaunch`。

如果 winget 不可用，先从 [Python 官网](https://www.python.org/downloads/windows/) 安装 Python 3.10 或更高版本，保留 Tcl/Tk 组件，再运行安装命令。安装脚本只对本次 PowerShell 进程使用执行策略参数，不修改全局执行策略。

## 同步自己的账户

新聊天中让 Codex 使用 `reset-reminder` 插件同步一次账户。标准安装的快照文件为 `%LOCALAPPDATA%\CodexResetPet\data\usage.json`。自定义安装位置时，告诉 Codex 安装目录，它可读取该目录的 `install.json` 确定数据目录。

快照格式是带时区的采集时间，以及内置 `get_usage_limits` 返回的账户状态。无需手工编造时间，也不要复制他人的快照。插件不读 auth.json、Cookie 或 API Key，不向社区网站发送账户数据。

桌面程序每 0.5 秒计算倒计时，每 5 秒读取本机快照。点击账户卡片的“刷新”可通过已登录的 Codex CLI 获取最新额度和重置时间，最长等待约 30 秒；失败保留上次数据。此操作不启动模型对话或定时任务。完整重置卡明细需要 Codex 再次同步；关闭 Codex 后，桌面宠物可以继续运行，但默认不会自动获知新额度、新卡和重置状态；主动开启下述临期自动使用后，会通过已登录 CLI 定期核对账户。快照超过 90 分钟会标为待同步，额度百分比淡化；日期和剩余时长仍按记录的截止时间变色。

同步失败时，原生任务和桌面显示可能不一致，应以最新官方账户状态为准。重置倒计时到零只是到达预计时间，不能证明额度已经到账。

手动刷新写入独立的 `desktop-usage.json`，不会覆盖完整账户快照。若 CLI 未提供卡到期明细，卡片会明确显示“上次记录”；手动刷新成功不代表旧卡记录也已核实。

## 可选定时提醒

### Tibo 网站预估（v0.4.8 功能）

第三张卡片“Tibo 预计重置”与账户额度、重置卡到期独立显示。它读取 `https://codex-reset.com/api/forecast?tz=Asia%2FShanghai` 的公开数据。精灵启动时读取一次，运行期间每 5 分钟再次读取；“更新预估”按钮可立即刷新。这个轮询不创建或启用 Codex 定时任务，不读取或发送账户信息，关闭精灵即停止。

网站提供结构化公告目标时，显示北京时间（精确到分钟）、“前”或“左右”、剩余时长，并使用与其他卡片相同的临近颜色。没有明确目标时显示“暂无明确预告”，可显示网站模型概率或最近观测记录。不会从概率或含糊的“明天/PST”文本推算日期。到期后显示等待确认，网站观测到重置也不代表本账户已到账。

预估保存在数据目录的 `tibo-forecast.json`。失败保留旧数据并标注“缓存/获取失败”；记录超过 1 小时标注“数据过期”，过期响应不会替换旧缓存。重连后可手动刷新，也会在下一次轮询重试。账户刷新和网站预估刷新互不替代。此功能已包含在 v0.4.8 发布包中。

“上次 Tibo 重置”卡片同时读取网站公开时间线，选择已确认或网站观测到的最近一次重置，排除预告、未来时间和重置卡发放。时间优先使用生效时间，其次观测时间，最后公告时间。优先显示网站中文公告说明，缺少翻译时显示原文；点击说明行的“详情”可阅读展开内容。只有缺少说明时才显示“网站暂无原因或公告说明”。网站的“事故相关”“里程碑”等分类单独列出，不当作官方原因，也不会把普通公告改写成确定的因果关系。点击“查看原帖”打开这条记录的来源。历史读取失败会显示“待获取”，不会让新的重置沿用上一条的原因，也不会丢弃成功更新的预估。

### Codex 账户提醒

安装不创建任务。想启用时明确让 Codex“每小时同步账户并检查 Tibo”。插件会在支持定时任务的宿主中创建当前聊天的任务；无变化保持安静，在账户接近重置、新社区消息或持续来源错误时提醒。

原生任务标题使用圆点颜色，因为它不提供自定义文字颜色；桌面窗口的时间文字可以渐变。停止 Codex 定时任务不影响桌面程序自身的额度轮询；可通过人物右键菜单单独关闭额度自动刷新。默认只显示最早有效重置卡到期时间，不自动兑换；临期自动使用是下述独立选项，不建立 Codex 定时任务。

## 临期重置卡自动使用（v0.4.8 功能）

默认关闭。右键人物 →“临期重置卡自动使用”，选择一种窗口：

- **到期前 16–6 分钟**：04:31 到期的卡从约 04:15 开始尝试，04:25 停止。
- **到期前 5 分钟至到期**：04:31 到期的卡从约 04:26 开始尝试，到期即停止。

窗口按服务端 expiresAt 的秒级时间计算，上述时刻为分钟显示。启用时核对并绑定当前账户，卡片下方显示执行状态；同一菜单可关闭。未进入窗口时最多每 5 分钟读取一次实时账户信息；进入窗口后失败约每 30 秒重试。倒计时接近窗口时会提前安排下一轮检查。使用前再次核对具体 ID、可用状态、到期时间和账户，只请求该卡 ID；不会调用让服务端自行选择卡片的兑换方式。当前无需重置时保留卡并在窗口内重试。

需本机 Codex 支持按 creditId 兑换，并返回完整实时卡片明细。程序优先查找桌面端自带的兼容 CLI，不读取凭证文件。旧版本仅返回数量、账户切换、缺少明细或状态不明时暂停，不拿旧快照作为使用依据。请求结果不明时只核实同一张卡，不改用下一张。

每张卡的兑换标识在请求前写入 auto-redeem-state.json，断网重试和重启复用同一标识。成功后重新获取额度，不猜测到账。配置 auto-redeem.json、兑换记录和锁文件属于个人运行数据，不应上传；请保留记录。关闭功能会阻止后续请求，已发出的请求无法撤回。

只有精灵运行、电脑唤醒且网络正常时才能执行；不会设置系统唤醒或重新开启已关闭的 Codex 定时任务。电脑恢复时若已超过窗口，不补用卡。此功能已包含在 v0.4.8 发布包。

## 动画和按钮

待机、点击、摸头、鼓脸、拖拽、落地、睡眠由状态机管理。10秒无主动互动后持续睡眠；静止悬停不算主动互动。按住鼠标不触发睡眠，松手重新计时。新动作直接覆盖旧动作，动作结束先更新状态再渲染，避免短暂闪入其他表情。

睡眠时 zzz 从头顶逐渐变大、上浮、淡出，持续循环。单击人物等待约 300 毫秒后切换气泡；相近位置双击触发摸头和轻笑，不切换气泡。拖远 180 像素会触发一次开心音。右键可关闭音效。`tibo reset` 使用系统默认浏览器打开固定公开网址，不提交任何账户信息。

## 更新与卸载

先右键人物，选择“退出桌面小精灵”，再在 **PowerShell** 运行：

```powershell
$f = Join-Path $env:TEMP 'codex-reset-pet-update.ps1'; Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/FantasyWorld-G/codex-reset-pet/main/update.ps1' -OutFile $f; powershell -NoProfile -ExecutionPolicy Bypass -File $f
```

更新器会查询 GitHub 最新稳定版，下载对应版本的安装器；安装器校验发布包 SHA-256，更新程序、插件及快捷方式，最后启动新版。保留 `data/` 中的账户快照、窗口位置和设置，不创建定时任务。更新失败时按提示处理后重试。

自定义安装目录的用户，在最后的命令末尾添加 `-InstallRoot 'D:\Apps\CodexResetPet'`，路径必须和原安装位置一致。仅安装桌面程序时可加 `-SkipPlugin`；暂不启动可加 `-NoLaunch`，不创建快捷方式可加 `-NoShortcut`。从源码目录直接运行的用户，应更新源码，或用 `install.ps1 -SourcePath .` 安装；本更新器面向安装器管理的目录。

更新后版本应为 `0.4.8`；双击人物可触发摸头，右键可开关语气音效。旧聊天可能仍使用插件缓存，插件更新后请开启新聊天。

更新前先从人物右键菜单退出程序，再运行新版本的安装命令。不同版本的程序放在 `app/<版本>`，`data/` 继续保留。重复安装当前版本会修复文件和依赖，更新桌面快捷方式；不会删除账户快照或自动启用定时任务。

卸载步骤：

1. 在 Codex 中关闭自己创建的重置提醒任务。
2. 从人物右键菜单退出小精灵。
3. 在 Codex 插件管理中卸载 `reset-reminder@codex-reset-pet`。
4. 删除桌面 `Codex Reset Pet` 快捷方式。
5. 如已注册命令，在 Windows“环境变量”的用户 Path 中移除自己安装目录的 `bin` 项。
6. 删除自己的安装目录。`data/` 中有快照和设置，需要保留时先复制到其他位置。

安装脚本没有添加 Windows 开机启动项，也不需要卸载系统中其他用途的 Python。

## 常见问题

**等待账户同步**：安装后尚未同步，或当前 Codex 宿主不支持账户状态工具。创建新聊天，调用插件同步一次。

**看不到插件**：重新打开 Codex 或新建聊天。检查 Codex CLI 是否可用；也可重新运行安装器以注册插件。安装器会明确报告跳过或注册失败，不会把失败说成成功。

**下载失败**：确认 GitHub Releases 和 PyPI 可访问，再重试。下载中断或 SHA-256 不匹配会停止安装。

**没有启动/异常退出**：查看安装目录 `data/desktop-events.log` 和 `data/desktop-crash.log`。反馈问题时可贴相关错误行，但不要上传 usage.json、state.json、登录凭证或整份个人数据目录。

**拖拽/透明显示异常**：程序使用 Windows 逐像素透明窗口。已有原生拖拽压力测试；远程桌面、系统缩放、显示驱动差异仍可能影响显示。请提供系统版本和触发步骤。

**电脑重启后没有宠物**：目前不设置开机自启，双击桌面快捷方式即可。

## 额度自动刷新（v0.4.8）

新安装、以及没有该设置的旧版升级，默认开启额度自动刷新。精灵启动时读一次，此后每次成功完成后等待 5 分钟再读。读取本机已登录 Codex CLI 的账户接口，不调用模型、不兑换重置卡、不建立 Codex 定时任务。人物右键菜单提供开关，保存为桌面设置中的 quota_auto_refresh；明确关闭后升级与重启都会保留。

按钮和后台轮询共用刷新通道，正在刷新时不重复请求。自动用卡检查与额度轮询不并发；若用卡检查已经拿到新额度，下一次只读刷新顺延 5 分钟。后台刷新不算人物互动，不唤醒睡眠、不播放音效。关闭自动刷新不关闭已经由用户明确开启的自动用卡；这两个开关彼此独立。

网络、登录或读取失败时保留旧缓存，依次等待 30、60、120、240、300 秒重试，后续失败最多每 5 分钟重试；成功后恢复正常间隔。手动按钮可立即重试。电脑恢复时若轮询到期，下一轮检查会发起一次请求，不补发休眠期间的所有轮次。退出程序取消请求。若卡片明细不在接口响应中，仍保留上次记录并标注待完整同步。
