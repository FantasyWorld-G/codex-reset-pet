# 小精灵非语言语气音

这组音效由本项目的 `scripts/generate_pet_sounds.py` 原创合成，用谐波、共振峰和气声表现轻声哼鸣、惊讶、鼓脸与困倦。没有台词、真人录音、外部音频采样或特定声优的声音复刻。音色属于风格化合成语气音。

| 文件 | 触发及语气 | 约时长 |
| --- | --- | --- |
| click_1.wav / click_2.wav | 轻点人物，两拍明亮短音 / 上扬撒娇音 | 0.47 / 0.46 秒 |
| pout.wav | 鼓脸，低鼻音后接一声呼气 | 0.67 秒 |
| drag.wav | 提起，短吸气后接高音惊讶 | 0.54 秒 |
| drag_happy.wav | 拖远后的三拍开心短笑 | 0.94 秒 |
| land.wav | 松手落地，两拍轻快短音 | 0.42 秒 |
| wake.wav | 唤醒，困倦哈欠和气声 | 0.89 秒 |
| sleep.wav | 每次进入睡眠，仅播放一次 | 3.00 秒 |

音效默认开启，右键人物可关闭并保存。单声道异步播放，新动作替换旧声音；拖拽过程和睡眠状态不会持续触发。普通待机、后台刷新不播放声音。睡眠音被唤醒打断；设备不可用或素材缺失不会阻塞动画，也不会发出系统提示音。

拖拽人物离起点达到 180 屏幕像素时，额外播放一次开心短笑；距离按窗口实际位移的直线距离计算，不累计来回抖动。继续拖动不会重播，松手或取消后下一次拖拽重新计数。拖动气泡不触发。开心音尚未播完就松手时，落地动画立即执行，但省略落地音，让短笑播完；其他新动作或静音仍可打断。

不同表情使用不同节奏、共振峰、气声比例和音高轮廓。睡眠为轻呼吸与渐弱叹息，严格保持 3 秒，不循环。

WAV 为 24 kHz、16 位 PCM。运行只用 Windows 自带音频接口，不新增音频依赖；重新生成资产才需要开发环境安装 NumPy。
